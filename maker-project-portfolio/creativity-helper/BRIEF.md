# Creativity Helper — absorbed into Fabrication Helper

This former standalone brief is now the **K2 Plus workspace** within `../fabrication-helper/PRODUCT.md`. It remains only as historical context.

## Purpose

Turn a maker idea plus optional images, videos, PDFs, notes, and links into a **Creality K2 Plus-focused** project brief: printable concept variants, part split plan, material choice, print-orientation rationale, assembly plan, risk register, and next experiments.

## MVP

1. Drag/drop local media and documents; calculate hashes and retain original provenance.
2. Extract metadata/transcripts locally where possible, including reference photos/videos of an object to reproduce or adapt.
3. Search only user-approved sources; show source links, dates, licensing uncertainty, and assumptions.
4. Translate the design into K2 Plus constraints: 350 mm cubed build envelope, print orientation, supports, wall count, infill, seam locations, and multi-material/color plan.
5. Recommend only known material roles: PETG/ASA for wet or outdoor prototype candidates after coupons; PLA for visual prototypes; unknown recycled filament for noncritical trials only.
6. Use a pluggable model router: local OSS/Nemotron-style endpoints when verified; hosted models only when explicitly configured by the user.
7. Produce `idea`, `print plan`, `assembly plan`, `evidence`, `assumptions`, `devil's advocate`, and `next safe experiment` sections.

## Non-goals

No silent web publishing, account sign-in, model download, cloud billing, professional-engineering claim, automatic slicer/printer control, or autonomous purchase/control.
