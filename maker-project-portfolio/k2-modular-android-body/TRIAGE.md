# Exoskeleton / Android Triage

## Priority

`ACTIVE TRIAGE / SAFETY-CRITICAL`

This is the primary robotics embodiment track.

## Current authorized engineering target

Stage 1: one modular, unpowered waist-to-below-knee mechanism on a bench rig or
weighted dummy.

## Flight extension status

`ACTIVE RESEARCH / HUMAN FLIGHT BLOCKED`

The Valkyrie flight-suit/air-taxi idea is now part of this project as a
separate aerial branch. Authorized work is limited to requirements,
simulation, failure analysis, inert folding geometry, and uncrewed test
planning. It does not authorize powered rotor work, human lift, outdoor flight,
casualty carriage, or operation over traffic.

## Definition of done

- Body dimensions and hip/knee axes are recorded.
- The common module interface is dimensioned.
- The mechanism moves through its specified range without binding.
- Mechanical hard stops work without software.
- Angle sensing is repeatable and timestamped.
- Backlash, fastener retention, and release time are measured.
- No human-worn powered test is required to pass this stage.

## Blockers before a human-worn test

- Independent mechanical and electrical safety review.
- Documented load cases and tested safety factor.
- Quick release reachable by the wearer and an observer.
- Physical emergency stop and power isolation.
- Torque, speed, current, travel, and temperature limits.
- Pinch-point guards and joint-alignment fitting procedure.
- Overhead fall protection and a test observer.
- A staged test protocol with explicit abort thresholds.

## Later stages

1. Full lower body through the feet.
2. Full-body exoskeleton.
3. Android configuration using the same modular interfaces.
4. Bounded independent robot trials after separate acceptance.
5. Optional aerial branch only after its independent simulation, uncrewed,
   aviation, and human-safety gates pass.
