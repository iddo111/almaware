# Scars addendum — night of 2026-08-17→18 (paid for tonight, binding on both rebuilds)

1. **A watchdog that restarts a HEALTHY app is the outage.** The old KESHEV-Watchdog restarted
   the mic every ~12 min all night: a silent room read as DEAF, decodes ending in GUARD_DROP/GATED
   read as MUTE, and the ~1 s startup pass through IDLE_NO_MIC read as STUCK. v2 laws: silence with
   heartbeats = QUIET not DEAF; a refusal-by-design (presence gate) is the app WORKING; a fault
   state must PERSIST before it restarts; "understands but never types" = visible alarm, never a
   restart (a restart is itself a 60 s break).
2. **The app must self-heal one level down.** Worker child killed at 05:58:12 → parent logged
   WORKER_DIED → WORKER_RESPAWN in 80 ms → decoding again in 15 s, parent never restarted. Proven
   live. Circuit breaker: 3 failure-respawns / 10 min, then WORKER_DOWN + alarm.
3. **Never call `bash` on this PC.** WSL is broken (HCS_E_HYPERV_NOT_INSTALLED); `bash -lc`
   silently resolves to it. The corpus push failed EVERY NIGHT since install because of this —
   the mic captured 135 MB of Iddo's voice and the trainer received zero bytes. Use native
   tar.exe/ssh.exe. And a push that leaves the remote inbox short is a FAILURE even if every
   command exited 0 — gatekeep by counting the far side.
4. **Never serve `http.server` under pythonw.exe** — sys.stderr is None and every request dies
   inside log_message before the response flushes. Looks bound, answers nothing.
5. **Reboot is a first-class failure mode.** 05:07 reboot killed every hand-started thing.
   Anything that must survive gets a logon task (hidden via run_hidden.vbs, delay, IgnoreNew) —
   and the app's own mutex makes double-starts safe.
6. **The training loop needs its own watchdog + gatekeeper** (Iddo's order): push verified by
   remote count; trainer promotes ONLY if it beats the deployed model on the reserved eval
   (Cafe-Claude 2026-06-25 / 07-01 — never trained on); a finished run that evaluated nothing
   promotes nothing.
