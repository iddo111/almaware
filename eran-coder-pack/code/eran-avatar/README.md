## Run (desktop window — tonight's deliverable)

Double-click `RUN-DEMO.cmd` (or the Desktop shortcut **ERAN Avatar demo**).

Keys: `1`=ba `2`=ma `3`=sha · `Space`=replay · `B`=A/B ba↔ma auto-alternate · `Esc`=quit.
Each syllable plays once at real speed with its wav (frame index driven by the audio playback position), then loops at 0.2× silently.

`--xr-mode off` in the launcher is deliberate: with SteamVR's OpenXR runtime installed and no headset, Godot's OpenXR module blocked at startup for the whole timeout (measured three times, 2026-09-09 04:10–04:20). For a Quest APK the project keeps `xr/openxr/enabled=true`.

## What is real and what is derived

| on screen | source |
|---|---|
| tube radius per section, `sqrt(A[i]/π)` (drawn ×1.6 radially, lengths true — stated on the label) | **measured** area function, 23 sections × 0.7292 cm, adult tract 17.60 cm |
| lips (face), `lip_open01 = sqrt(A[22]/3.813)` | **measured** |
| constriction ring / tongue: `argmin(A)`, `min(A)`, cm from lips | **measured** |
| nasal branch + nose glow: `velum > 0.05` | **measured** (a switch, MOUTH-MANUAL §1.4) |
| glottis / throat glow: `voicing` | **measured** |
| burst puff at `t_release` (first ms where `min(A) ≥ 0.01` after a sealed run) | **measured** |
| jaw | **DERIVED** from the front-cavity mean `A[17..22]` — not in the data, labelled so in the HUD and on the face |

## Pipeline

```
school/<syl>.json  --tools/export_articulation.py-->  data/articulation.json  --Godot 4.6-->  scenes/main.tscn
   (13-dim keyframes)     geometry.py + tract_core.py         (60 fps, 21 syllables, 237 KB)
                          AGE_MONTHS=300, N=23 -- mouth2.py is NEVER imported (it is the 15-section child)
```

The exporter refuses to write unless the /a/ vowel area function reproduces the brief's reference row exactly (it does: max |diff| 0.0000; narrowings 0.384 cm² at section 9 and 0.277 at section 16, as MOUTH-MANUAL §1.1 documents). Every wav duration equals its gesture duration to the millisecond.
