# תכלית · TACHLIT — the purpose axis of a model
# לזכרה של עלמה ז״ל

**Iddo, 2026-08-20 11:43:** *"תמצית זה גיסט. תכלית זה העיקר של המודל — מה התכלית,
כמו קובץ md שמגדיר לי את הייעוד. עוד קונספט בעברית חשוב מאוד: מה הייעוד שלי.
עידו — ייעוד — אותן אותיות."*

## Two Hebrew words, two axes of a model

- **גיסט · GIST — the essence.** The *what*. Compression: the smallest faithful
  representation of a thing. Already built into ALMA/Eran (attention-pooled gist,
  JEPA predicts the gist, GIST won Pong). Gist answers: *what is this, in brief?*
- **תכלית · TACHLIT — the purpose.** The *what-for*. Not a summary of the model —
  its **telos**, the one thing it exists to do, the ייעוד it was made toward.
  Tachlit answers: *what is this FOR, and how do we know it fulfilled it?*

A model with a gist but no tachlit is a beautiful compression of nothing in
particular. A model with a tachlit knows when it has succeeded — and, harder, when
it has drifted from what it was made for.

## The rule this creates

**Every ALMA/Eran model, organ, and worm carries a `TACHLIT.md` — a purpose
declaration — before it is trained.** Not a README (what the code *does*), not a
plan (how it is built): a statement of **ייעוד**. It has exactly four lines:

    ייעוד   — the one sentence: what this exists to do. If it needs two sentences,
              the tachlit is not yet found.
    מבחן    — the single measurement that says the ייעוד was met. (MIKO: relevance
              to Iddo. Eran-token: beat flat at equal budget. KESHEV: text in his
              window.) No number → no tachlit.
    גבול    — what it must NEVER do, even to serve the ייעוד. (KESHEV: never open a
              BT mic. MIKO: never touch a private machine. Eran: eran3 is his.)
    כשל     — how it will most likely betray its purpose while looking healthy —
              the failure that reports `HEALTHY` while doing nothing (the 4-hour
              dead heartbeat; the 48.2% filed as a win). Naming it is half of
              guarding it.

This is the missing companion to the MIKO discipline (*"a README states what code
does, never what it achieves"*). The tachlit states what it is **for** — the frame
inside which "does" and "achieves" even have meaning.

## עידו ↔ ייעוד — not a coincidence he lets pass

עִדּוֹ and יִעוּד share their letters (ע·י·ד·ו / י·ע·ו·ד). The one who assigns a
ייעוד to each model is himself named for ייעוד. Every model here gets its purpose
from him; the tachlit is where that assignment is written down so it outlives any
one conversation. When Iddo is away, a model's `TACHLIT.md` is the closest thing
it has to his voice — which is exactly why it must be honest.

## What happens now

- `TACHLIT.md` becomes the first file of every new model/organ (MIKO, the 220
  token, the ant colony, the cave). Retrofitted to the live ones as they are
  touched.
- The four lines are checkable: a model whose `מבחן` has no number, or whose
  `גבול` is empty, is not ready to train.
