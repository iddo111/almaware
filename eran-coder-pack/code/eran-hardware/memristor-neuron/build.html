נוירון־ממריסטור מכוונן חשמלית Electrically-Tunable Memristor-Neuron — Build Guide  v1.0

משקלים = אלמנטים אנלוגיים שמתכווננים פיזית וחשמלית  ·  פרספטרון מכני עם לולאת אימון סגורה  ·  ALMAWARE

הרעיון בשורה אחת: נוירון שבו כל משקל אינו מספר בזיכרון אלא גוף פיזי — קבל משתנה שמסובב סרוו, מוט גרפיט עם מגנט־טבעת, מגנט שנופל בצינור נחושת. ערך המשקל נקבע חשמלית (PWM / זרם סליל), האותות מסוכמים במגבר־שרת, והפלט עובר הפעלה (activation). לולאת שגיאה סגורה (target − output) מזיזה את המנועים ומכווננת את המשקלים — כך המערכת לומדת.

1 · עקרון

נוירון מלאכותי מחשב y = φ( Σᵢ wᵢ·xᵢ + b ). בנוירון הזה כל wᵢ הוא רכיב אנלוגי שערכו נשלט חשמלית ותלוי־היסטוריה (memristive):

(א) קבל משתנה מסובב־סרוו משקל A

שני מערכי לוחות אלומיניום (או שני גלילי רדיד) משולבים. סרוו הובי מסובב את הרוטור ומשנה את שטח החפיפה ⇒ הקיבול C נקבע ע"י זווית = ערך משקל שנשמר מכנית וניתן להגדרה חשמלית ב-PWM.

C = ε₀·εᵣ·(N−1)·A(θ) / d

(ב) גרפיט + מגנט + צינור נחושת משקל B

מוט גרפיט בשרוול אלומיניום = נגד/אלקטרודה משתנה. מגנט־טבעת ניאודימיום הוא גם מסה (משקל פיזי) וגם קובע מגע/מיקום. כשהמגנט נע בצינור נחושת נוצר בלימת זרמי־מערבולת ⇒ תגובה תלוית־היסטוריה (memristor-like).

R_graphite = ρ·ℓ(pos)/A  ;  F_eddy ∝ −v

טופולוגיה: כניסות x1,x2 → משוקללות ע"י אלמנטים אלה → מסוכמות בצומת מסכם (op-amp) → הפעלה (משווה+דיודה) → פלט y. אות השגיאה e = target − y נכנס לנהג אקטואטורים שמסובב סרוו / מזיז מגנט ⇒ עדכון משקל.

2 · סכמה חשמלית

איור 1 — הסכמה המלאה: שני משקלים אנלוגיים מכווננים (Cw1 סרוו, Rw2 גרפיט/מגנט) → מסכם U1 → הפעלה U2+D1 → פלט y → מגבר-שגיאה U3 → MCU → נהגי סרוו/סליל. הקווים המקווקווים הם לולאת האימון הסגורה.
y = φ( 1/Cw1·∫x₁dt  +  (Rf/Rw2)·x₂  +  b )    |    Δw ∝ η·e·x  (e = target − y)

4 · הרכבה שלב-אחר-שלב

1משקל A — הקבל המסובב

  • גזור 2 סטים של 5–7 לוחות אלומיניום חצי-עגולים (או גלגל 2 גלילי רדיד־אלומיניום על ציר משותף עם מפריד מיילר דק כדיאלקטרי).
  • הסט הקבוע = סטטור, הנע = רוטור על ציר הסרוו SG90. חפיפה מלאה ≈ 40–120pF, חפיפה 0 ≈ 5pF.
  • חבר את שני האלקטרודות לענף כניסת x1 ולצומת המסכם דרך R1.

2משקל B — גרפיט + מגנט + צינור נחושת

  • הכנס מוט גרפיט (מחוד עיפרון 2–5mm) לשרוול אלומיניום; קצה אחד קבוע = אלקטרודה, השני נוגע דרך מגנט הטבעת שמשמש גם מסה וגם מגע.
  • הצב את המגנט בתוך צינור הנחושת האנכי. תנועתו איטית (eddy) — זה נותן את ההיסטרזיס ה-memristive.
  • לפף את הסליל (~200 ליפופים, חוט מגנט 0.3mm) סביב קטע הצינור; זרם בסליל דוחף/מושך את המגנט ⇒ משנה מגע ⇒ משנה Rw2.

3הצומת המסכם (U1)

  • כניסה הופכת (−) = צומת סיכום וירטואלי; כניסה (+) לאדמה. משוב Rf 100k ∥ Cf 1nF ⇒ מסכם-משלב.
  • הזרם מכל ענף משוקלל: ענף x2 לפי Rf/Rw2, ענף x1 לפי הקיבול Cw1. b = נגד קיבוע דרך מקור עזר.

4הפעלה (U2 + D1)

  • מוצא U1 נכנס למשווה U2 מול סף Vθ. מוצא U2 עובר דיודה D1 ⇒ y חצי-גל (spike חיובי).
  • עומס RL 10k לאדמה מקבע את הפלט.

5לולאת השגיאה (U3 + MCU + נהגים)

  • מגבר-הפרש U3 מחשב e = target − y.
  • ה-MCU דוגם e ב-ADC ומחשב Δw = η·e·x; מפעיל PWM לסרוו (Cw1) וזרם לסליל (Rw2).
בדיקת שפיות בין שלבים: הזרם 1V DC ל-x1/x2 ומדוד את מוצא U1 במולטימטר — עלייה/ירידה חלקה כשמסובבים ידנית את הסרוו / מזיזים את המגנט מוכיחה ששני המשקלים חיים לפני חיבור הלולאה.

5 · לולאת האימון העצמי (Closed-loop)

הלולאה היא פרספטרון מכני: השגיאה מזיזה מסות פיזיות עד שהפלט תואם. פסאודו-קוד ה-MCU:

loop every 20 ms:
  y      = analogRead(A0) * k         // measured neuron output
  target = analogRead(A1) * k         // desired label
  e      = target - y                 // error
  // gradient step on each physical weight:
  servoPos += ETA * e * x1            // Cw1  (rotate variable cap)
  coilPWM   = clamp(coilPWM + ETA*e*x2, -255, 255)  // Rw2 (move magnet)
  servo.write( clamp(servoPos, 0, 180) )
  driveCoil( coilPWM )                // DRV8833 bipolar current
  // convergence: |e| below tol for N steps  ->  learned

עדכון Hebbian/perceptron: Δw ∝ η·e·x. η (learning rate) נקבע ע"י גודל צעד הסרוו/זרם. התכנסות = |e| קטן מסף לאורך זמן.

7 · בטיחות

  • מתחים נמוכים בלבד (≤ ±9V) — אין סכנת חשמל, אבל קצרים שורפים מגברים. בדוק קוטביות לפני הפעלה.
  • מגנטים חזקים (NdFeB): הרחק מקוצבי-לב, כרטיסי אשראי, דיסקים. יכולים לצבוט אצבעות — טפל בזהירות.
  • גרפיט: אבק גרפיט מוליך — נקה שאריות שלא יגרמו לקצרים על הלוח.
  • סליל/מנוע: הוסף דיודת flyback (1N4148) על הסליל להגן על נהג המנוע מקפיצות מתח.
  • חום: אל תעמיס — עבודה כבדה של אימון ארוך רצה על ה-MCU, לא על ה-PC.

8 · מה מוכיח שזה עבד

  1. למידת XOR/AND דו-כניסתי: הזן טבלת אמת, הפעל את הלולאה, והראה ש-|e|→0 וש-y מפריד נכון בין המחלקות.
  2. גרף התכנסות: תעד servoPos, coilPWM ו-e לאורך צעדים — ירידה מונוטונית של השגיאה = למידה אמיתית, לא מקרית.
  3. מבחן החזקה (memristive): נתק מתח לדקה; החזר. אם המשקל נשמר (הסרוו במקום, המגנט לא זז) — יש זיכרון פיזי. זה מה שמפריד ממריסטור מפוט' רגיל שמאבד מצב.
  4. ניצחון על הוניל (או לא): הרץ את שתי הגרסאות על אותה בעיה; דווח מי התכנס מהר יותר ובאיזו שגיאה סופית. תוצאה שלילית = תוצאה כשרה.
  5. יציבות שעה: תן לנוירון המאומן לרוץ שעה על אותה כניסה; הפלט צריך להישאר יציב (זה מבחן ה-ALMA — עובד >שעה, אמיתי לא הדגמה).

9 · הוכחה בפועל (סימולציה מאומתת) PASS

הרצנו את sim.py — מודל טהור (100% שלנו, ללא תלויות) של הנוירון עם המשקלים הבדידים האמיתיים: קבל מונע-סרבו (181 מצבים), MCP41010 (256 מצבים), ורעש גאוסי על צומת-הסיכום (ADC + סובלנות קבל). מול בקרת vanilla עם משקלים רציפים אידיאליים. אותה בעיה, אותו כלל עדכון.
