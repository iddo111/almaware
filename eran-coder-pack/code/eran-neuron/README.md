# eran-neuron — ערן הביולוגי 🧠

הזרע הרץ של הגישה הביולוגית לבניית AI. **לא טרנספורמר. לא עוזרת. יצור.**
stdlib בלבד — נועד לרוץ ולא להישבר.

## עקרונות
1. **הצורה היא האלגוריתם** — הטופולוגיה נבנית, לא רק המשקלים.
2. **חיבור = יחס, לא סקלר** — צרור ערוצים (משרעת, פאזה, שער) + אפשר טקסט/מדיה/קוד.
3. **מספר פתוח** של כניסות ויציאות — לא רוחב קבוע.
4. **זמן וירי** — ספייקים, פאזה, מצב פנימי; לא סכום סטטי.
5. **מצפן כארכיטקטורה** — בית-דין/קוורום מובנה (3 → 71).
6. **מעבר לביולוגיה** — הביולוגיה השראה, לא כלא. יחידה משלנו.

## מה בנוי ומאומת ✅
| קובץ | מה | סטטוס |
|---|---|---|
| `neuron.py` | נוירון עשיר (כניסות/יציאות פתוחות, ערוצים, פאזה/התאבכות, ירי, למידה יחסית) + **בית-דין 3** (קוורום מדורג) | רץ, דטרמיניסטי |
| `rich_connection.py` | קשת מולטימודלית: מספרים + פרומפט + GIF + סאונד + קוד | רץ |
| `pong.py` | 🐛 תולעת מול 🐙 תמנון — פונג בספייקים, נוירונים יורים גלויים | רץ, הוגן |

**ממצא מעניין (pong):** התמנון (8 זרועות) ניצח 3:2 — אבל התולעת (2 נוירונים) התמודדה עם **חצי מהספייקים** (39 vs 67). *הקטן והרזה יעיל יותר.*

## מפת דרכים
- **v1 (יש):** מנוע נוירון + חיבור עשיר + פונג-דמיון. ✔
- **v2 מדעי:** מנוע ביופיזי (Izhikevich/AdEx/HH — mV, ms, מוליכויות) לצד מצב-הדמיון. מתג מצב.
- **v2 קונקטום:** להריץ על נתוני C. elegans / זבוב האמיתיים ב-`../almaware-brain-lab` → לכיוון "תחליף לניסוי" (רף פרופ' יעל חפץ).
- **פרימיטיב חדש:** יחידת טורינג/אוטומט/"פופ-קוק-צוץ" (Tsetlin, Neural-CA כתקדים) — יחידה אחת אלגנטית קודם.
- **מחשב קבלי "עמוס":** ספירות=צמתים, אור ישר/חוזר=forward/backprop, אותיות=טוקנים. לע"נ הרב עמוס גואטה זצ"ל.
- **מוסך-נוירונים:** UI גרף-צמתים (ComfyUI × Incredible Machine × Claude-CLI) 2D→3D→VR.
- **התגלמות:** קשירה ל-RC-car (`../rc-car-pico`) — נוירונים → נהיגה.

