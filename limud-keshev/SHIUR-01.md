## טבלת רוזטה: פסקל → פייתון

| מה | פסקל (1996) | פייתון (2026) |
|---|---|---|
| השמה | `x := 5;` | `x = 5` (בלי נקודה-פסיק, בלי :=) |
| הדפסה | `WriteLn('שלום');` | `print("שלום")` |
| בלוק | `begin ... end;` | **הזחה** — 4 רווחים במקום begin/end |
| תנאי | `if x > 5 then ... else ...` | `if x > 5:` ואז שורות מוזחות, `else:` |
| לולאה | `for i := 1 to 10 do` | `for i in range(1, 11):` |
| while | `while x < 10 do` | `while x < 10:` |
| פונקציה | `function Kaful(x: integer): integer;` | `def kaful(x):` ואז `return x * 2` |
| מערך | `array[1..10] of integer` | `lst = []` ואז `lst.append(7)` — גדל לבד! |
| מחרוזת | `s: string;` | `s = "טקסט"` — בלי הכרזות טיפוס בכלל |
| הערה | `{ הערה }` | `# הערה` |

**שלושת ההלמים של יוצאי פסקל:** אין `;` — שורה נגמרת בסוף שורה. אין הכרזות —
משתנה נולד כשמשתמשים בו. **ההזחה היא החוק** — מה שמוזח שייך לבלוק, נקודה.

## תרגיל השיעור: יומן v0.1 — הצעד הראשון של קשב-של-עידו

היומן הוא לב המיקרופון (חוק 3 בספר הצלקות: "לעולם לא לאבד דיבור").
אתה כותב אותו. פתח פנקס-רשימות (או Notepad++), כתוב **בעצמך** (לא העתק-הדבק —
הידיים חייבות להרגיש), ושמור בשם `D:\CLAUDE\limud-keshev\yoman.py`:

```python
# yoman.py - גרסה 0.1, הקוד הראשון של עידו מזה 30 שנה
import datetime

def ktov_shura(kovetz, hodaa):
    zman = datetime.datetime.now().isoformat()
    with open(kovetz, "a", encoding="utf-8") as f:
        f.write(zman + " | " + hodaa + "\n")

def kra_hakol(kovetz):
    with open(kovetz, "r", encoding="utf-8") as f:
        return f.readlines()

# --- התוכנית עצמה ---
ktov_shura("yoman.txt", "השורה הראשונה שלי אחרי 30 שנה")
ktov_shura("yoman.txt", "פסקל היה אתמול, פייתון זה היום")

shurot = kra_hakol("yoman.txt")
for shura in shurot:
    print(shura.strip())

print("סך הכל", len(shurot), "שורות ביומן")
```

**מה חדש פה לעומת פסקל:** `with open(...)` פותח קובץ **וסוגר לבד** (אין Close!);
`"a"` = append כמו APPEND בבייסיק; `f-strings` עוד מחכים לשיעור 2.
