# ERAN // AWAKENING

Ten-second ALMA Studio teaser assembled from verified, locally generated assets.

- Image: FLUX.2 Klein on Eran3 / DGX3
- Motion: Wan 2.2 TI2V on Eran3 / DGX3
- Music: ACE-Step 1.5 on Eran4 / DGX4
- Finish: FFmpeg, 1920x1080 SDR, H.264/AAC

The imagery is AI-generated and is not represented as documentary footage. Source
canaries remain unchanged. The project works from additive copies with source
hashes recorded in `project.json` and the render receipt.

Run `render.ps1` from PowerShell to reproduce the master.
