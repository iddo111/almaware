# מנוע חיפוש תורני — הצי על ליקוטי מוהר"ן  
**מה צריך:**  
- מחשב ישן (או Raspberry Pi 4, ~250 ש"ח)  
- דיסק קשיח חיצוני (1–2 טרה, ~200 ש"ח)  
- גרסה חינמית של *Llama.cpp* או *Ollama* (להפעלת מודל לינוקס-לוקלי)  
- קובץ *ליקוטי מוהר"ן* בפורמט טקסט (מאת מיזם砚经, חינמי)  
- Python 3.8+, ספריות: `transformers`, `sentence-transformers`, `faiss-cpu`  

**איך עושים:**  
1. **הכנת Corpus:** הורד את *ליקוטי מוהר"ן* מ[砚经](https://www.sefaria.org/Likutei_Moharan) (בפורמט JSON/Text), נקה מסימנים מיותרים.  
2. **הטמעה ווקטורית:** השתמש במודל *Hebrew-BERT* (או *TaBERT*) כדי להפוך כל פסקה ל-embedding (vektor). שמור ב-`faiss` (מאגר מהיר לחיפוש דמיון).  
3. **הפעלת מודל:** הורד מודל *Mistral-7B-he* (מוכן-ל-Hebrew) דרך Ollama, הפעל ב-`ollama run mistral-he`.  
4. **הטמעה של Context:** בקשת חיפוש → חפש דמיון ב-`faiss` (10 תוצאות), שלח את ה-context + השאלה למודל, ובקש תשובה *בשפת התלמיד* (למשל: "הסבר ב-3 שורות").  
5. **ממשק פשוט:** Flask web app (או حتى Streamlit) עם שדה חיפוש + כפתור "הסבר לי".  

**זמן ועלות:**  
- זמן: 3–5 ימים (למפתח מנוסה)  
- עלות: ~450 ש"ח (אם אין לך רכיבים)  
- אם כבר יש לך מחשב: 0 ש"ח (רק זמן)  

**טיפ אלוף:**  
הוסף *tagging* אוטומטי לפי נושאים: "תפילה", "תשובה", "חג", "תורה וعمل". אפשר לעשות זאת עם מודל classification קטן (למשל `distilbert-base-hebrew`) שמתאמן על 500 דוגמאות ידניות.  

**בטיחות:**  
- המודל פועל *במחשב האישי* – לא שולח שום נתונים ל-Cloud.  
- אם תרצה לשתף: הפעל את ה-`Llama.cpp` עם `--no-offload` כדי למנוע גישה חיצונית.  
- לא שומרים שום היסטוריה – רק ה-embeddings של התנ"ך/תורה.

**בטיחות:**

# מדריך DGX הביתי — הספר שאין: קלאסטר בסלון  
**מה_needed:**  
- 4 מחשבים ישנים (או 4 Raspberry Pi 5, ~1500 ש"ח)  
- רשת Gigabit Ethernet (כבלים + Switch, ~200 ש"ח)  
- Ubuntu Server (חינם)  
- Slurm (חינם)  
- Docker (חינם)  

**איך עושים:**  
1. **התקנת Ubuntu:**  
   - כל מחשב → Ubuntu Server.  
   - מתקינים NVIDIA drivers (אם יש כרטיסים), או רק CPU (ל-Raspberry).  
2. **התקנת Slurm:**  
   - אחד כ-"master", Others כ-"workers".  
   - מגדירים `slurm.conf` – 4 nodes, 16 cores.  
3. **התקנת AI Stack:**  
   - Docker Compose:  
     ```yaml
     services:
       ollama:
         image: ollama/ollama:latest
       jupyter:
         image: jupyter/datascience-notebook
     ```  
4. **הפעלת מודל:**  
   - ב-Jupyter: `import torch; model = torch.load("mistral-7b")`  
   - שולחים job ל-Slurm: `sbatch train.sh`  

**זמן ועלות:**  
- זמן: 1–2 שבועות (למתחיל)  
- עלות: ~1700 ש"ח (אם קונים Pi5)  
- אם יש לך מחשבים ישנים: 0 ש"ח  

**טיפ אלוף:**  
הוסף *dashboard* ב-Grafana – מראה usage של כל node.  
השתמש ב-*Hugging Face Hub* – למשוך מודלים ישירים.  

**בטיחות:**  
- לא מחברים ל-Internet – רק LAN פנימי.  
- כל מחשב עם סיסמה.  
- לא שומרים weights חיצוניים.
