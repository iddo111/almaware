## 741. מדריך קול לעיוורים באתרים — הצי מקריא ומנווט  
**מה צריך (חומרים זולים)**  
- מחשב נייד/טאבלט ישן (או Raspberry Pi 4) – עד 200 ₪  
- מיקרופון USB זול (כגון Fifine K669) – 30‑50 ₪  
- רמקול או אוזניות עם חיבור 3.5 מ״מ – 20‑40 ₪  
- תוכנה חינמית: **NVDA** (קורא מסך) או **eSpeak NG** + **PocketSphinx** לזיהוי דיבור  
- חיבור אינטרנט (Wi‑Fi)  

**איך עושים (צעדים מספריים)**  
1. התקינו את מערכת ההפעלה המועדפת (Linux Lite או Windows 10 LTSB) על המחשב/רצפי.  
2. הורידו והתקינו את NVDA (ל‑Windows) או eSpeak NG + Orca (ל‑Linux).  
3. חיברו את המיקרופון ובדקו שהוא מזוהה במערכת (`arecord -l` בלינוקס או בקרת קול ב‑Windows).  
4. התקינו את חבילת זיהוי הדיבור: `pip install pocketsphinx` (או השתמשו ב‑Google Speech‑to‑Text API בחינם עד מכסה יומית).  
5. כתבו סקריפט פשוט שמקשיב לפקודה קולית כמו “קרא את העמוד” או “לך לקישור הבא”. לדוגמה ב‑Python:  
   ```python
   import speech_recognition as sr, webbrowser, time
   r = sr.Recognizer()
   with sr.Microphone() as source:
       print("הגיד פקודה...")
       audio = r.listen(source)
   try:
       cmd = r.recognize_google(audio, language='he-IL')
       if "קרא" in cmd:
           # כאן ניתן לקרוא את הטקסט באמצעות NVDA/eSpeak
           os.system('nvdaControllerClient -s "התחל קריאה"')
       elif "לך לקישור" in cmd:
           webbrowser.open("https://example.com")
   except:
       print("לא הבנתי")
   ```  
6. חברו את הסקריפט לקיצור דרך על שולחן העבודה כדי שניתן יהיה להפעיל אותו בלחיצה אחת או בפקודה קולית קבועה.  
7. בדקו באתר אינטרנט פשוט (למשל ויקיפדיה בעברית) שהקריאה והניווט עובדים בצורה חלקה.  
8. שמור את ההגדרות כ‑profile כדי שניתן יהיה לטעון אותם במכשיר אחר בקלות.  

**זמן ועלות**  
- זמן הרכבה: 2‑3 שעות (כולל בדיקות).  
- עלות כוללת: ~300‑450 ₪ (תלוי אם יש לכם מחשב ישן).  

**טיפ של אלוף**  
השתמשו ב‑**Wake Word** זול כמו “אלמה” בעזרת ספריית **Porcupine** (הגרסה החינמית מאפשרת מילה אחת) כדי שהמערכת תהיה תמיד מוכנה להקשיב ללא צורך בלחיצה על כפתור.  

**בטיחות**  
- וודאו שהמיקרופון לא ממוקם קרוב למקורות רעש חזקים (מאוורר, מזגן) כדי למנוע הפעלות שווא.  
- אם אתם משתמשים ב‑Raspberry Pi, חיברו אותו למקור מתח יציב (5V/2.5A) והשתמשו במאוורר קטן כדי למנוע התחממות יתר.

## 742. ארכיב שיחות מוקלט למשפחה — 'תשאל את סבא' לנצח  
**מה צריך (חומרים זולים)**  
- סמארטפון ישן או מכשיר הקלטה זול (כגון Zoom H1n) – עד 150 ₪  
- כרטיס microSD 32 GB – 20‑30 ₪  
- מחשב או NAS ביתי לאחסון (можно להשתמש בדיסק חיצוני ישן) – 0‑100 ₪ אם יש לכם כבר  
- תוכנה חינמית: **Audacity** לעריכה, **ffmpeg** לדחיסה, **Syncthing** לסינכרון אוטומטי  
- מיקרופון קלאוורד (lavaliere) זול – 15‑25 ₪ (להקלטה ברורה)  

**איך עושים (צעדים מספריים)**  
1. הטעינו את המכשיר והכניסו כרטיס microSD ריק.  
2. חברו את המיקרופון הקלאוורד למכשיר ובדקו את רמת הקלט (מטרה: -12dB עד -6dB בפיקים).  
3. קבעו נוהל הקלטה: לפני כל שיחה, הציגו את התאריך והשם (“היום 12/03/2025, מדבר עם סבא יצחק”).  
4. הקליטו את השיחה בפורמט WAV (16‑bit, 44.1 kHz) לאיכות מקסימלית.  
5. לאחר סיום ההקלטה, העבירו את הקובץ למחשב דרך כרטיס ה‑SD או באמצעות Bluetooth.  
6. ב‑Audacity, בצעו נורמליזציה והסרת רעש בסיסי (Noise Reduction).  
7. המירו את הקובץ ל‑OPUS או AAC ב‑ffmpeg כדי לחסוך מקום:  
   ```bash
   ffmpeg -i input.wav -c:a libopus -b:a 64k output.opus
   ```  
8. שמור את הקבצים בתיקייה מאורגנת לפי שנה/חודש/שם (`2025/03/יצחק_סבא_1203.opus`).  
9. התקינו **Syncthing** על המחשב ועל מכשיר גיבוי (נאס או מחשב שני) כדי שהקבצים יסונכרנו אוטומטית לענן ביתי.  
10. צרו אינדקס פשוט בקובץ CSV או JSON עם שדות: שם, תאריך, קישור לקובץ, תיאור קצר (ניתן למלא בעזרת תמלול אוטומטי עם **Whisper** קטן).  

**זמן ועלות**  
- זמן ההתקנה הראשונית: 1‑2 שעות.  
- זמן עיבוד לכל הקלטה: 10‑15 דקות (כולל העברה והמרה).  
- עלות כוללת: ~200‑350 ₪ (אם יש לכם סמארטפון ישן).  

**טיפ של אלוף**  
השתמשו ב‑**Whisper tiny** (מודל פתוח) על Raspberry Pi כדי ליצור תמלול אוטומטי ברמת דיוק סבירה (>80%) בעברית אחרי שתאמנו אותו על כמה דקות של דיבור משפחתי. זה יהפוך את החיפוש לשאלות כמו “מה סבא אמר על מלחמת ששת הימים?” למיידי.  

**בטיחות**  
- שמור עותק גיבוי במקלט פיזי (דיסק חיצוני) במקרה של תקלה בנאס.  
- אל תשמור קבצים ברשת ציבורית ללא הצפנה; השתמשו ב‑Syncthing עם הצפנה end‑to‑end או ב‑VeraCrypt כדי להגן על הפרטיות המשפחתית.

## 743. מחולל חידונים משפחתיים — מהתמונות והסיפורים שלכם  
**מה צריך (חומרים זולים)**  
- מחשב נייד/טאבלט ישן (או Raspberry Pi 4) – עד 200 ₪  
- מצלמת אינטרנט זולה או שימוש במצלמת הסמארטפון – 0 ₪ אם יש  
- חשבון חינמי ב‑**Google Photos** או **Nextcloud** לאחסון תמונות  
- ספריית Python: **Pillow**, **fuzzywuzzy**, **flask** (לשרת אינטרנט קל)  
- מדפסת ביתית זולה (אופציונלי) להדפסת כרטיסי חידון – 0‑150 ₪  

**איך עושים (צעדים מספריים)**  
1. העלו את כל התמונות המשפחתיות לתיקייה משותפת ב‑Google Photos (הגדרו אותה כ‑“ציבורי רק לקישור”).  
2. על המחשב, התקינו את Python 3 ואת הספריות:  
   ```bash
   pip install pillow fuzzywuzzy flask
   ```  
3. כתבו סקריפט שסורק את התיקייה, מוציא מטא‑דטא (תאריך, מיקום אם קיים) ויוצר שאלות מסוג:  
   - “מי זה בתמונה?” (תמונה + 4 אפשרויות)  
   - “באיזה שנה צולמה התמונה?” (מהתאריך EXIF)  
   - “מה הסיפור מאחורי התמונה?” (משתמש מזין תשובה חופשית, המערכת בודקת דמיון fuzzy).  
4. שמור את השאלות בקובץ JSON עם המבנה:  
   ```json
   { "id":1, "type":"pic", "question":"מי זה?", "image":"img123.jpg", "options":["סבא","סבתא","דוד","בן"], "answer":"סבא" }
   ```  
5. הפעילו שרת Flask מקומי שמגיש את החידון בדפדפן:  
   ```python
   from flask import Flask, render_template, request, jsonify
   app = Flask(__name__)
   # טעינת השאלות מ‑JSON
   @app.route("/")
   def index():
       return render_template("quiz.html")
   @app.route("/answer", methods=["POST"])
   def answer():
       data = request.json
       # בדיקת תשובה ושליחת משוב
       return jsonify({"correct":True, "feedback":"כל הכבוד!"})
   if __name__=="__main__":
       app.run(host="0.0.0.0", port=5000)
   ```  
6. עיצבו תבנית HTML פשוטה (`quiz.html`) עם כפתורי בחירה ותמונה גדולה.  
7. בדקו את החידון במכשיר ביתי (טאבלט או טלפון) דרך הרשת המקומית.  
8. (אופציונלי) הדפיסו את התמונות ואפשרויות התשובה על כרטיסים בגודל 10×15 ס״מ לשימוש פיזי במפגשים משפחתיים.  
9. שמור גרסה של הקוד ב‑GitHub פרטי כדי שניתן יהיה לעדכן ולהרחיב בקלות.  

**זמן ועלות**  
- זמן פיתוח ראשוני: 3‑4 שעות (כולל כתיבת הסקריפט ובדיקה).  
- עלות: ~0‑200 ₪ אם יש לכם מחשב/טאבלט ישן; אחרת עד 350 ₪ עבור Raspberry Pi + מארז + כרטיס microSD.  

**טיפ של אלוף**  
הוסיפו “מצב זיכרון” שבו המערכת מציגה תמונה ומבקשת מהמשתמש להקליט סיפור קצר בקול; לאחר מכן משמיעים את ההקלטה למשתתפים האחרים – זה מוסיף ממד אישי ומעמיק את הקשר המשפחתי.  

**בטיחות**  
- אם אתם משתמשים בשרת אינטרנט ביתי, וודאו שהפורט פתוח רק לרשת המקומית (למשל דרך הגנת הראוטר) כדי למנוע גישה חיצונית לא מותרת.  
- אל תעלו תמונות רגישות (מסמכים, תעודות זהות) לאחסון ציבורי ללא הצפנה; השתמשו ב‑Google Photos עם שיתוף מוגבל או ב‑Nextcloud עם הצפנה בצד השרת.

## 744. בוט תיאום מפגשים — מוצא זמן לכולם בלי פינג-פונג  
**מה צריך (חומרים זולים)**  
- שרת קטן או VPS חינמי (למשל Oracle Cloud Free Tier, AWS Free Tier) – 0 ₪  
- חשבון בוט ב‑Telegram (או Discord) – חינמי  
- ספריית Python: **python‑telegram‑bot**, **dateparser**, **pytz**, **icalendar**  
- גוגל קאלנדר API (חינם עד מכסה יומית) – נדרש חשבון גוגל  
- קובץ `.env` לאחסון מפתחות בטוח (можно להשתמש ב‑`python-dotenv`)  

**איך עושים (צעדים מספריים)**  
1. צרו בוט ב‑Telegram דרך @BotFather וקיבלו את ה‑TOKEN.  
2. על השרת, התקינו את הסביבה:  
   ```bash
   sudo apt update && sudo apt install python3-pip -y
   pip3 install python-telegram-bot dateparser pytz icalendar python-dotenv
   ```  
3. הגישו את גוגל קאלנדר API:  
   - נכנסו ל‑Google Cloud Console → יצרו פרויקט → הפעילו את Google Calendar API.  
   - הורידו את קובץ ה‑credentials.json ושמרו אותו בתיקיית הפרויקט.  
4. כתבו קובץ `.env` עם המשתנים:  
   ```
   TELEGRAM_TOKEN=123456:ABC...
   GOOGLE_CREDENTIALS=./credentials.json
   TIMEZONE=Asia/Jerusalem
   ```  
5. פיתחו את הלוגיקה של הבוט:  
   - כאשר משתמש שולח `/schedule`, הבוט שואל את הטווח הרצוי (תאריך התחלה וסיום).  
   - הבוט שולח לכל המשתמשים בקבוצה הודעה עם אפשרויות זמן (לדוגמה, שלוש חצאי שעות פנויות).  
   - כל משתמש מגיב עם ✅ או ❌; הבוט אוסף את התשובות ומחשב את החיתוך (הזמן שבו כולם אמרו ✅).  
   - אם אין התאמה מלאה, הבוט מציע את הזמן עם הכי הרבה ✅ ומבקש הסכמה.  
   - לאחר אישור, הבוט יוצר אירוע בגוגל קאלנדר של המארגן ושולח קישור לכל המשתתפים.  
6. השתמשו ב‑`dateparser` כדי להבין משפטים בעברית כמו “מחר בערב” או “יום שלישי בשעה 19:00”.  
7. הריצו את הבוט בתהליך נפרד (למשל באמצעות `screen` או `systemd`) כדי שירוץ 24/7.  
8. בדקו עם קבוצה של 3‑5 חברים שהבוט מוצא זמנים ללא צורך בהודעות חוזרות.  
9. הוסיפו פקודה `/myevents` כדי להציג את האירועים הקרובים מהקלנדר של המשתמש.  

**זמן ועלות**  
- זמן פיתוח ובדיקה: 4‑5 שעות.  
- עלות: 0 ₪ אם משתמשים בשרת חינמי; אחרת VPS זול ~5‑10 ₪ לחודש.  

**טיפ של אלוף**  
הטמיעו פקודה `/prefer` שמאפשרת לכל משתמש להגדיר זמנים “לא נוחים” (לדוגמה, לא רוצה פגישות אחרי 20:00). הבוט יוציא אפשרויות שמכבדות את ההעדפות האוטומטית – זה מפחית משמעותית את מספר הסיבובים הנדרשים.  

**בטיחות**  
- שמור את קובץ ה‑credentials.json מחוץ לתיקייה הציבורית של השרת (למשל ב‑`~/private/`).  
- אם אתם משתמשים ב‑VPS ציבורי, הגבילו גישה לפורט הבוט רק לכתובות IP שלכם או השתמשו ב‑SSH tunneling.  
- אל תאחסנו מפתחות בטוחים בקוד המקור; השתמשו במשתני סביבה או ב‑Vault כמו HashiCorp Vault במצב פיתוח.

## 745. תחנת רדיו ALMAWARE — סטרים של דרוויש 24/7  
**מה צריך (חומרים זולים)**  
- Raspberry Pi 4 (2 GB) או מחשב נייד ישן – עד 250 ₪  
- כרטיס microSD 32 GB – 20‑30 ₪  
- חיבור אינטרנט יציב (קווי או Wi‑Fi)  
- תוכנה חינמית: **Icecast** (שרת שידור), **FFmpeg** (להמרה וזרימה), **MPlayer** או **VLC** (לנגן מקורות)  
- מקור אודיו: פלייליסט של דרוויש (ניתן להוריד מאתר חינמי כמו Jamendo או מאוסף יצירות ברישיון CC) – 0 ₪  
- מיקרופון אופציונלי להזנת שידורים חיים – 15‑25 ₪  

**איך עושים (צעדים מספריים)**  
1. התקינו Raspberry Pi OS Lite על כרטיס ה‑SD (בעזרת Raspberry Pi Imager).  
2. חיברו את ה‑Pi לרשת והגישו לו כתובת IP קבועה דרך DHCP reservation בנתב.  
3. התקינו את Icecast:  
   ```bash
   sudo apt update
   sudo apt install icecast2 -y
   sudo systemctl enable icecast2
   sudo systemctl start icecast2
   ```  
4. ערכו את קובץ ההגדרה `/etc/icecast2/icecast.xml`:  
   - שינו את `<source-password>` ו‑`<admin-password>` לסיסמאות חזקות.  
   - הגבירו את `<port>` ל‑8000 (ברירת מחדל).  
   - הפעילו את `<authentication>` כדי למנוע גישה לא מורשית.  
5. הכינו תיקיית מוזיקה (`/home/pi/music`) והעתיקו אליה את קבצי הדרוויש בפורמט MP3 או OGG (מומלץ OGG ליעילות רוחב פס).  
6. כתבו סקריפט ב‑bash שמזרים את הקבצים במעגל ל‑Icecast via FFmpeg:  
   ```bash
   #!/bin/bash
   MUSIC_DIR="/home/pi/music"
   while true; do
       for f in "$MUSIC_DIR"/*.ogg; do
           ffmpeg -re -i "$f" -c:a libopus -b:a 64k -f opus icecast://source:hackme@localhost:8000/almastream
       done
   done
   ```  
   - שמור כ‑`/home/pi/stream.sh`, עשו לו `chmod +x`.  
7. הפעילו את הסקריפט בתהליך רקע (למשל באמצעות `screen` או `systemd` service).  
8. בדקו את הזרימה על ידי פתיחת דפדפן והקלדה `http://<IP_PI>:8000/almastream.m3u` ב‑VLC או במכשיר נייד עם אפליקציה שמקבלת זרמי Icecast.  
9. (אופציונלי) חיברו מיקרופון USB והגדירו את FFmpeg לקלוט ממנו ולמערבב עם המוזיקה live (לשידורים חיים של דרוויש או שיחות).  
10. פרסמו את הקישור בקבוצת משפחה, בפורומים או באתר אינטרנט פשוט שבניתם עם GitHub Pages.  

**זמן ועלות**  
- זמן התקנה והגדרה: 2‑3 שעות.
