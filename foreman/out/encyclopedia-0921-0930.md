# 921. Pi-hole לכל הבית — פרסומות נעלמות מכל מכשיר

**מה צריך (חומרים ומחירים זולים):**
*   **מחשב ישן או Raspberry Pi Zero 2 W:** כל מכשיר שאפשר להריץ את לינוקס (Raspberry Pi 3, 4, או Zero) יעבוד. מחיר מינימלי: 50-100 ש"ח.
*   **כרטיס SD:** כרטיס SD אחסון (מינימום 16GB, מומלץ 32GB או 64GB Class 10).
*   **כבל Ethernet:** לחיבור ישיר למודם או לראוטר (חינם אם יש בבית).
*   **מקדם חיבור (Power Supply):** ל-Raspberry Pi (5V 2.5A או יותר).
*   **דיסק קשיח חיצוני (USB):** אופציונלי אך מומלץ מאוד לשמירת הבסיס נתונים על מנת לא להכביד את ה-SD.

**איך עושים (צעדים מעשיים):**
1.  **הכנת החומרים:** קנו את ה-Raspberry Pi והכרטיס SD. אם אתם משתמשים במחשב ישן, ודאו שהוא מצויד בכרטיס רשת (NIC) ויכול לרוץ את מערכת ההפעלה הקלה (למשל DietPi או Raspberry Pi OS Lite).
2.  **התקנת המערכת:** הכניסו את הכרטיס למחשב, והפעילו את תוכנת "Raspberry Pi Imager". בחרו ב-Raspberry Pi OS Lite (ללא שולחן עבודה) כדי לחסוך משאבים. הקליטו את המערכת לכרטיס.
3.  **הפעלת המכשיר:** הכניסו את ה-Raspberry Pi לרשת הביתית, חברו את הכבל האלחוטי או האתרי, והפעילו אותו.
4.  **התקנת Pi-hole:** עלו למכשיר דרך SSH (או במסך משתמש אם אין SSH). הפעילו את פקודת ההתקנה המהירה:
    ```bash
    curl -sSL https://install.pi-hole.net | bash
    ```
5.  **הגדרת ה-DHCP:** במהלך ההתקנה, יש לבחור את האפשרות "Is this your DHCP server?". אם כן, יש להגדיר את Pi-hole כשרת DHCP. אם לא (כמו ברוב הבתים שיש להם ראוטר אחר), תצטרכו להעתיק את כתובת ה-IP של ה-Pi-hole ולהגדיר את הראוטר שלכם להעביר כל הבקשות DNS ל-Pi-hole.
6.  **הגדרת המכשירים:** עדכנו את ה-Router שלנו כך שה-Pi-hole יהיה השרת המרכזי לפתרון שמות. כעת, כל מכשיר ברשת (חיבור עם כבל או אלחוטי) ישתמש ב-Pi-hole כדי לפתור כתובות דומיין, והפרסומות ייחסמו באופן אוטומטי.
7.  **ניהול:** פתחו את הדפדפן וכתבו את כתובת הניהול (לרוב `http://pi.hole/admin`) כדי לראות אילו דומיינים נחסמו ולהוסיף רשימות חסימה מותאמות אישית.

**זמן ועלות:**
*   **זמן:** כ-30 דקות להתקנה והגדרה.
*   **עלות:** כ-100 ש"ח להקמת מערכת מלאה.

**טיפ של אלוף:**
*   **"הגדר חיסון חוץ-ביתי (DNS-over-HTTPS):"** כדי שהפרסומות לא יצטרכו לחסום רק בבית, הגדירו ב-Pi-hole חיבור לשרתי DNS ציבוריים כמו Cloudflare (1.1.1.1) או Quad9, והגדירו אותם כ-"Blackhole". כך, גם כשאתם משתמשים בנייד בחוץ, הפרסומות נחסמות באותו אופן.

**בטיחות:**
*   ודאו שאתם משתמשים בכבל Ethernet כאשר מתקינים את המערכת לראשונה, כדי להבטיח שהמכשיר יתחבר לרשת ולא תיפול התקנה בגלל בעיות אלחוט.

# 922. מראה LAN לספריות קוד — עצמאות מהאינטרנט

**מה צריך (חומרים ומחירים זולים):**
*   **שרת זעיר:** Raspberry Pi 4 או Zero 2 W (כ-100 ש"ח).
*   **מערכת הפעלה:** גרסה קלה של לינוקס (למשל DietPi או Ubuntu Server).
*   **כבלים:** כבלי Ethernet לחיבור השרת לראוטר ולמחשבים.
*   **שטח אחסון:** כרטיס SD או דיסק קשיח חיצוני (USB) לשמירת הקבצים.

**איך עושים (צעדים מעשיים):**
1.  **בחירת הפתרון:** תלוי בצרכים, יש שתי דרכים. דרך אחת היא להשתמש בשירות קיים כמו GitLab CE (Community Edition) שרץ בשרת עצמאי. הדרך השנייה היא להשתמש בכלי קוד פתוח כמו Gitea (קל משמעותית מ-GitLab) או Gogs.
2.  **התקנת Gitea:** התקינו את Gitea על ה-Raspberry Pi. זהו כלי שמאפשר לכם להקים שרת Git פרטי. הורידו את הגרסה המתאימה לארכיטקטורה שלכם (למשל ARM64) והפעילו אותה.
3.  **הגדרת השרת:** יש להגדיר את Gitea כך שהוא יכתוב לכבל ה-SD או לדיסק החיצוני, ולא לזיכרון הזמני (RAM), כדי למנוע אובדן נתונים במקרה של התרעה.
4.  **גישה מהרשת:** ודאו שהשרת מאפשר גישה מהרשת המקומית (LAN). תצטרכו לפתוח פורטים מסוימים ב-firewall של הראוטר (בדרך כלל 22 ל-SSH ו-3000 ל-Gitea).
5.  **התחברות:** מכל מחשב ברשת, כתבו בדפדפן את כתובת ה-IP של השרת והגדירו משתמש ראשון. כעת אתם יכולים ליצור ריפוזיטוריה (repository) חדשה, לגנוב קוד מ-GitHub ולשמור אותו ברשת הביתית שלכם.
6.  **עבודה מקומית:** כדי לעדכן קוד, התקינו את כלי Git על המחשבים והשתמשו בפקודות `git clone`, `git pull`, ו-`git push` כדי לשלוח ולקבל קבצים בין המכשירים בלי להתחבר לאינטרנט.

**זמן ועלות:**
*   **זמן:** כ-1-2 שעות להתקנה והגדרה.
*   **עלות:** כ-100 ש"ח לשרת.

**טיפ של אלוף:**
*   **"הפעלת גיבויים אוטומטיים לכבל:"** הגדירו כרונולוג (Cron job) על השרת שיגבה את כל ספריות הקוד יומית לדיסק חיצוני או לשרת נוסף בבית. כך, אם ה-Raspberry Pi תיכשל, הקוד שלכם יישמר במקום אחר.

**בטיחות:**
*   ודאו שאתם משתמשים ב-HTTPS עם תעודה מסומנת (Self-signed certificate) כדי להצפין את התקשורת בין המחשבים לשרת, ושהפורטים סגורים לגישה מהאינטרנט החיצוני.
