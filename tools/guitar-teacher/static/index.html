Theory — the why

Notes & the chromatic scale

12 notes, repeating: A A# B C C# D D# E F F# G G#. Frets on a guitar = half steps. Two half steps = a whole step. The fretboard is just this 12-note loop, shifted across 6 strings.

Intervals (the building blocks)

Distance between two notes. Counted in half-steps:
0 = unison, 1 = m2, 2 = M2, 3 = m3, 4 = M3, 5 = P4, 6 = TT, 7 = P5, 8 = m6, 9 = M6, 10 = m7, 11 = M7, 12 = octave.
You hear them constantly: P5 (Twinkle Twinkle 1st leap), M3 (Oh When the Saints), m3 (Greensleeves).

Major scale formula

W W H W W W H (W=whole, H=half). C major from C: C D E F G A B C. Every major scale follows the same pattern from its root. Learn this and you can build every major scale on the fretboard.

Chord = stacked thirds

A triad = root + 3rd + 5th from a scale. C major triad: C (root) + E (M3) + G (P5). Minor triad: lower the 3rd by a half-step. C minor = C + Eb + G. Every chord shape on the guitar is a way to grab these three notes (or four, for 7ths).

The CAGED system

Five movable shapes (C-A-G-E-D) cover the entire fretboard for any major chord. Learn them once → play any major chord anywhere. Then minor / 7th variants drop in by tweaking 1-2 notes.

Keys & the cycle of fifths

Move up a 5th: add a sharp. Move down a 5th: add a flat. Order: C→G→D→A→E→B→F#→… This is why so many songs in G use G–C–D and so many in D use D–G–A. The I–IV–V chords are always built from the same three scale degrees.

Modes (advanced)

Start the major scale from a different degree → different mode. From C major: starting on D = D Dorian (jazzy minor), starting on E = E Phrygian (Spanish/metal), starting on G = G Mixolydian (rock dominant). Same notes, different vibe — depends what you treat as "home".

Rhythm: subdivisions & strumming

4/4 = 4 quarter notes per bar. Strum down on each beat = D D D D. Add up-strums on the "and" of each beat = D U D U D U D U (8th notes). The classic folk strum: D D U U D U (count 1 2 & & 4 &). Practice with metronome at 60 bpm, slow.

Ear training (5 minutes a day)

Sing intervals against a drone. Hum the root, then play P5, then P4, then M3. Brain learns the colors. Theta-band practice apps: Functional Ear Trainer (Android, FOSS). Adds up fast.

Jam — "Zoom for Musicians"

Zoom is built for talk — it adds 200–600ms latency and crushes audio. Useless for jamming. Real low-latency audio needs a music-specific tool. All picks below are FOSS.

SonoBus — top pick (audio-only)

FOSS, peer-to-peer, ~20-50ms round-trip on the same continent. Cross-platform (Win/Mac/Linux/iOS/Android). No server needed for small groups — public servers free.
Install: sonobus.net → download → pick "Connect to a public server" → share group name with the other musician → both pluck strings.
Latency budget: under 30ms feels like the same room. 30-60ms = tolerable. Over 80ms = falling apart. SonoBus shows your live RTT.

Jamulus — central server model

FOSS, needs a public Jamulus server (free list at jamulus.io). Great if everyone in same region. Slightly more setup than SonoBus.

JackTrip — pro-grade (Stanford CCRMA)

Originally academic, now FOSS. Lowest latency of all three but needs more network setup (UDP ports). Recommended once you outgrow SonoBus.

Video adds 100-300ms more delay and competes for bandwidth — start audio-only. Add video later by running Zoom alongside SonoBus (use Zoom muted for visual cues, SonoBus for sound).

Repo — "GitHub for Musicians"

Version control for songs, stems, DAW projects. Branch ideas, roll back mistakes, collaborate without overwriting.

Splice — the de-facto industry tool

Commercial, free tier. Auto-saves every DAW project save → cloud → version history → diff (visual + audio) between any two versions. Roll back any session. Branches not as elegant as Git but works for non-coders. splice.com

Git + Git LFS — pure FOSS

For coders. Treat your DAW project folder as a Git repo, use Git LFS for the big audio files (stems, samples). Branch song ideas freely. Diff/merge text-format stuff (Reaper RPP, Tracktion XML). Less friendly for non-coders.
Setup: git init, git lfs install, git lfs track "*.wav" "*.als" "*.cpr", git add .gitattributes, then commit.

BandLab — collaborative DAW + version history

Web-based DAW with built-in versioning + cloud + multi-user editing. Less powerful than Ableton but the collaboration model is the cleanest of any I've used. Free. bandlab.com

For Iddo's setup specifically: D:\music-repo\ as a Git LFS repo per song, hosted on a private Gitea instance (FOSS) on your Tailscale network. Tell me when ready and I'll spin up Gitea in a container.

DAW integration

No official MCPs exist for Ableton or Cubase yet. Workable bridges below.

Ableton Live — Max for Live + OSC

Ableton ships with Max for Live (M4L). Patches exist that expose Live's API via OSC (Open Sound Control). A custom MCP can speak OSC → control Live: trigger clips, mute tracks, change BPM, automate. Library: AbletonOSC (FOSS).
Build path: thin MCP server in Python that wraps AbletonOSC + exposes trigger_clip(track, scene), set_bpm, etc. as tools.

Cubase / Nuendo — Generic Remote + MIDI

Cubase doesn't have a public scripting API. Workaround: Generic Remote setup maps any MIDI CC → any Cubase function. An MCP can send virtual MIDI (via loopMIDI) → Cubase responds. Less granular than Ableton.

Reaper — full scripting (best for AI control)

If you can switch / supplement with Reaper: full ReaScript API (Python + Lua), Web Interface, OSC built-in. Easiest DAW to AI-control. FOSS-friendly license. Worth considering for AI-collab work.

Universal Audio Bridge — Ableton Link

Ableton Link sync across DAWs + apps (Live, Reason, Logic, mobile apps, even Reaper) — same beat clock. Not control, just sync. Useful for jam-session timing.

Practice routine (20 min)

  1. Warm-up (3 min): Chromatic exercise 1-2-3-4 on each string, slow → fast.
  2. Tuning (1 min): Tuner tab. All 6 strings green.
  3. Chord changes (5 min): Pick 2 chords (e.g. G ↔ C). Switch every 4 beats with metronome at 60 bpm. Count successful switches in 1 min.
  4. One new thing (5 min): One new chord shape, scale, or theory concept. Tab in this app.
  5. Play a song (5 min): Songs tab. Even messy. Fun > perfect.
  6. Cool-down (1 min): Improvise on any 2 notes you like.

Daily consistency > weekend cramming. 20 min × 7 days > 2 hours × 1 day.
