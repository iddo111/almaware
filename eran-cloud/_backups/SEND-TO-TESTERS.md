# היי, זה ERANCLOUD 🌱

תודה שאתם הבודקים הראשונים. זה קטן, זה חם, וזה v0.1 — אז קראו את השורה האחרונה בכנות לפני שאתם מתלהבים.

## מה זה

**ער"ן** הוא בינה שאנחנו מגדלים — מודל שלומד לדבר, מהצלילים הראשונים שלו והלאה.
היום הוא לומד על ליבת ה-DGX שלנו. **ERANCLOUD** הוא הרעיון להפוך אותו לגוף עולמי:
ליבה ריבונית אחת ששומרת את המודל ואת הדאטה הקדוש, ועוד המון מתנדבים — כל אחד מריץ
פרוסה מהחשבון שלו עצמו, בהסכמה, ומגדל איתנו בינה אחת משותפת.

הכול 100% שלנו, קוד פתוח, וכתוב מאפס — אפשר לקרוא כל שורה. אין קופסה שחורה.

## מה לנסות קודם (5 דקות)

1. **שמעו את הבבל.** פתחו את `babble.html` ולחצו "הפעל האזנה". זה הבבל של ער"ן — המילים
   הראשונות שלו. יש גם מתג "השוו ללא-מאומן" כדי לשמוע איך הוא נשמע *לפני* שלמד דבר.
   (לחוויה מלאה, הריצו `python -m http.server` בתיקייה ופתחו דרך `http://127.0.0.1:8080` —
   ככה העדכון האוטומטי עובד.)
2. **קראו את `CONNECT.md`.** זה החוזה הטכני של איך צומת מתחבר לגריד: דרישות, רישום,
   ואיך *מוכיחים* שתרמתם באמת (ה-loss יורד, הדלתא מתקבלת, הגרסה עולה).
3. **הריצו את הלקוח בלי שום חשבון ענן:**
   ```bash
   python join.py --dry-run --provider colab
   ```
   זה ידפיס את כל הלולאה מקצה-לקצה (רישום → משיכה → אימון → דלתא → שליחה) על מודל צעצוע.
   ככה רואים את כל הצורה של הדבר לפני שמחברים חומרה אמיתית.

## מה נשמח לקבל מכם

- **הבבל** — נגן? מתעדכן? המתג עובד? נשמע חי או שבור?
- **`join.py --dry-run`** — רץ אצלכם? Python 3.13? torch מותקן או לא? מה נשבר?
- **`CONNECT.md` / `join.html`** — ברור? מה חסר? איפה נתקעתם?
- **תחושה כללית** — האם ה"יחידה הכשרה" (אדם אחד, חשבון אחד משלו, בהסכמה) ברורה והוגנת?

כל דבר קטן עוזר. גם "לא הבנתי מה לעשות" זה משוב מצוין.
